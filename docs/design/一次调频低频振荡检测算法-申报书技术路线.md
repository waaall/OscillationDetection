# 一次调频系统低频振荡检测算法 — 技术路线与功能描述


## 一、功能定位

针对一次调频控制对象，对单通道实时信号进行在线频谱分析，识别电网/机组中 **0.01 Hz – 1 Hz 量级的低频振荡**，向上层控制器输出振荡告警与主导频率/幅值，作为调频策略调整与故障防误动判据。

> 备注：频带上限取至 1 Hz 时，要求采样率 ≥ 5 Hz（即 `period_ms ≤ 200 ms`），以保证对最高目标频率留出足够工程余量。

## 二、主要功能

1. **低频振荡在线识别与告警**：在目标频带内出现显著周期性振荡时，置位告警标志 `ALARM`。
2. **主导频率与幅值输出**：分别输出
   - 目标频带内主峰（`DOMIN_FREQ_HZ` / `DOMIN_PEAK_AMP`）
   - 全正频域主峰（`OVERALL_PEAK_FREQ_HZ` / `OVERALL_PEAK_AMP`，不含 DC）

   便于上层区分"带内振荡"与"带外干扰"。
3. **运行时阈值联动**：`AMP_THRESHOLD` 支持在线修改，无需等待下一次 FFT 即可影响告警判定。
4. **采样周期自适应**：基于每周期上送的 `period_ms` 自动推导采样率与窗口点数；周期相对漂移超过阈值（默认 0.5%）时自动重建 FFT 状态。
5. **完备状态控制**：覆盖使能 `ENABLE` / 清窗复位 `RESET` / 窗口未灌满 / 异常输入等情形，所有场景下 `READY` / `ALARM` / 频率幅值输出均有明确语义。

## 三、技术路线

```
样本输入 → 环形缓冲滑窗 → 时间顺序重排 → 线性去趋势 → Hann 窗 →
        实数 FFT → 单边谱 & coherent gain 校正 →
        全频域 / 目标频带峰值搜索 → 三点抛物线插值 → 告警判定 → 输出
```

关键技术要点：

1. **滑窗缓冲**：环形缓冲区在线维护最新窗口；FFT 前重排为时间连续序列，避免回绕造成的时间断点对低频段的污染。
2. **预处理链**：
   - **线性去趋势（最小二乘）**：抑制慢漂移、斜坡背景对低频成分的泄漏；
   - **Hann 窗**：降低频谱泄漏，旁瓣抑制稳定。
3. **FFT 计算**：采用成熟实数 FFT 实现，以双精度浮点参与运算，源码级编入算法库，避免引入独立动态依赖。
4. **峰值搜索与频率细化**：
   - 全正频域主峰排除 DC；
   - 目标频带按 `ceil(f_min/Δf)` / `floor(f_max/Δf)` 严格映射到 bin；
   - 三点抛物线插值（约束 `|δ|≤0.5`）修正频点栅格化误差。
5. **幅值归一化**：单边谱 + Hann 窗 coherent gain 校正，使主峰幅值近似对应等效正弦峰值，从而让 `AMP_THRESHOLD` 在不同窗口长度、不同样本回放下保持可比。
6. **滑窗 + 步长触发**：首次窗口灌满立即出结果；之后每 `STEP_DURATION_S` 重算一次频谱，期间复用缓存仅按当前阈值重判 `ALARM`，兼顾响应速度与计算开销。
7. **双重约束运行时校验**：每周期校验 Nyquist 约束 `f_max < f_s/2`；并在采样周期发生实质漂移时自动清窗重建，保证频率轴标定正确。

## 四、主要参数

| 参数 | 含义 | 取值范围 |
| --- | --- | --- |
| `TARGET_FREQ_MIN_HZ` | 目标频带下限 | 0.005 ~ 0.15 Hz |
| `TARGET_FREQ_MAX_HZ` | 目标频带上限 | 0.1 ~ 1 Hz |
| `WINDOW_DURATION_S` | 分析窗口时长 | 20 ~ 1024 s |
| `STEP_DURATION_S` | 滑动步长 | 1 ~ 10 s |
| `AMP_THRESHOLD` | 振荡告警幅值阈值 | 按现场信号幅值标定 |
| `PERIOD_CHANGE_REINIT_RATIO` | 采样周期重建阈值 | 0.1% ~ 1% |

须同时满足核心约束：`f_max < f_s/2`（Nyquist），`WINDOW_DURATION_S ≥ 3 / f_min`（低频可分辨）。

## 五、技术特点与可行性

- **可集成**：以稳定 ABI 形式封装为动态库，便于嵌入既有调频控制平台。
- **计算成本可控**：步长触发将 FFT 频次与刷新节奏解耦，长窗口下仍可在嵌入式平台稳定运行。
- **结果可解释、阈值可复用**：明确的幅值口径让现场调参经验可在不同回放数据间迁移。
- **数值稳健**：全链路有限值检查、动态分配失败显式处理、异常输入主动清状态，避免 NaN 传播污染告警链。
- **易扩展**：在不破坏现有接口的前提下，可平滑增加进入/退出滞回、连续命中判定、噪声底估计、带外强峰抑制等增强能力。
