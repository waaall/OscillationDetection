# 一次调频系统低频振荡在线检测 — 招标技术方案

## 一、背景

一次调频是电力系统应对频率扰动的第一道防线，对维持电网安全、稳定运行具有重要意义。在实际运行中，由于调速、励磁等多个调节环节之间的相互作用，机组与电网之间常会出现持续性的周期性功率振荡，振荡周期通常处于 1 秒至 100 秒之间，行业内称为"低频振荡"。

低频振荡若不能被及时识别与处置，可能带来如下不利后果：

- 机组出力反复波动，加剧设备机械与热应力损耗；
- 一次调频品质下降，影响并网考核成绩；
- 严重时威胁机组与所在区域电网的运行安全。

因此，具备实时低频振荡监测能力的检测功能，是提升一次调频性能、保障机组与电网安全的重要技术手段。

## 二、目标

一套面向一次调频应用场景的低频振荡在线检测系统，实现：

1. 对机组关键运行信号的连续在线监测；
2. 自动识别落入低频振荡频段内的显著周期性振荡；
3. 实时输出振荡告警信号及振荡特征参数；

## 三、系统功能

1. **实时振荡检测与告警**：对接入的运行信号进行连续监测，一旦发现目标频段内出现显著振荡，立即触发告警。
2. **振荡特征输出**：在告警的同时，同步输出当前主要振荡频率与振荡幅度，便于运行人员判断振荡严重程度并辅助原因分析。
3. **带内振荡与带外干扰区分**：系统同时报告"目标频段内主导振荡"与"全频段最强振荡成分"，便于区分需要重点关注的低频振荡与无需处理的带外干扰。
4. **告警门限运行可调**：振荡告警门限支持在运行过程中实时调整，便于结合机组工况与运行经验灵活整定，无需停机或重启。
5. **完整的运行状态管理**：支持远程启停控制、状态复位、采集异常自检等运行管理功能，运行状态语义清晰、便于上层系统理解与调度。
6. **采集环境自适应**：当采集周期发生波动或运行参数变化时，系统能够自动重新校准内部状态，确保检测结果始终可信。

## 四、技术方案

系统采用成熟的"信号采集 → 数据净化 → 频谱分析 → 振荡识别 → 告警输出"五段式技术路线：

1. **信号采集**：以滑动时间窗口方式持续接收实时运行数据，保证检测结果反映最新运行状态。
2. **数据净化**：自动消除信号中的直流偏置与缓慢漂移，并对窗口数据做适当的加权处理，避免缓慢趋势被误判为低频振荡，提高频率成分识别的准确性。
3. **频谱分析**：采用工业界广泛验证的频谱分解方法，将一段时间窗口内的信号精确分解为不同频率成分，得到各频率成分的能量分布。
4. **振荡识别**：在用户设定的目标频段内搜索最强振荡成分，结合高精度频率细化方法降低估计误差，并将振荡幅度与告警门限比较，给出告警判定。
5. **告警输出**：将识别结果以标准化接口形式输出，包括告警标志位、主导振荡频率与振荡幅度，供上层控制与监控系统使用。

为兼顾告警响应速度与计算资源占用，系统采用周期性更新策略：每隔规定时长重新进行一次频谱分析，期间沿用最近一次有效结果，并随时根据最新告警门限重新判定，确保门限调整能即时生效。

## 五、系统优势

- **检测频段适用面广**：可覆盖一次调频场景下常见的超低频至约 1 Hz 范围的低频振荡，能够满足绝大多数实际工况下的振荡监测需求。
- **频率估计精度高**：在常规频谱分析的基础上引入高精度频率细化方法，告警结果可直接用于辅助判断振荡来源与传播特征。
- **告警门限可解释、可复用**：系统内部对振荡幅度采用统一规范化口径，使得在不同工况、不同历史数据回放中的门限经验可以稳定迁移与复用，便于现场长期积累调参经验。
- **高可靠性**：系统内置完整的异常自检与自恢复机制，在采集中断、参数突变等异常情况下能够安全切换到无效结果状态，避免错误告警，满足电厂控制系统对长期稳定运行的严格要求。
- **资源占用低**：通过周期性触发的频谱计算策略，可在嵌入式控制器或现场工控机上稳定运行，无需新增专用硬件投入。
- **易集成、易升级**：检测功能以独立软件模块形式提供，可平滑接入现有控制系统；后续在保持现有接口不变的前提下可继续扩展告警延时、连续命中判定、噪声背景估计等增强功能，具备良好的可持续演进能力。

## 六、工程实施可行性

1. **技术成熟**：方案核心算法基于工业界广泛应用的频谱分析理论，技术路线清晰、实现风险可控。
2. **接口标准**：检测模块对外提供标准化输入/输出接口，便于与现有控制系统对接，原有系统无需做大规模改造。
3. **部署灵活**：支持就地部署与集中部署两种方式，可根据机组现场条件灵活选择。
4. **可验证、可回归**：系统支持基于历史运行数据的离线回放验证，便于在正式投运前对告警门限与目标频段配置进行充分校核。
5. **运维友好**：运行状态语义清晰、关键参数可在运行中在线调整，显著降低现场运维难度。

## 七、对采集环境的基本要求

为保证检测结果的可靠性，对接入信号的采集环境提出如下基本要求：

- 采集信号需保持连续、稳定，采集周期不应频繁大幅波动；
- 当目标频段上限取至 1 Hz 时，要求信号采集频率不低于 5 Hz（即采集周期不大于 200 毫秒），以保证对最高目标频率留出足够工程余量；
- 接入信号应能反映被监测对象的真实功率/频率波动特征，避免引入额外的滤波延迟或非线性处理。
